# Security Policy

Foya can read files, run commands, and access networks. Do not open a public
issue for vulnerabilities involving unauthorized access, command execution,
credential exposure, path traversal, or approval and sandbox bypasses.

Report vulnerabilities through GitHub
[Private vulnerability reporting](https://github.com/freesoulcode/foya/security/advisories/new).
Only the latest `main` branch is currently supported.

Please include:

- The affected version, platform, and component.
- The impact and required preconditions.
- Minimal reproduction steps or a proof of concept.
- A suggested fix, if available.

Remove API keys, tokens, personal paths, conversation content, and other
sensitive data from logs or screenshots. Use the bug report template for
non-security defects.
