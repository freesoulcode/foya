# 自定义智能体

Foya 支持用户级和项目级自定义智能体。智能体定义是静态配置;每次执行都会创建独立 Child Session,拥有隔离的上下文窗口、事件流和取消信号。

## 文件位置

```text
用户级：$HOME/.agents/agents/{name}.md
项目级：{workspace}/.agents/agents/{name}.md
```

项目必须先注册到 Foya,项目级定义才会被发现。未指定作用域且名称冲突时,项目级定义优先;也可以使用 API 返回的完整 `ref` 显式选择。

## 文件格式

```markdown
---
name: market-researcher
description: 分析市场规模、竞争格局和增长驱动因素
model: gpt-5
tools:
  - read
  - web_search
  - web_fetch
max_turns: 12
timeout: 10m
---

你是一名市场研究分析师。

结论必须引用证据,并明确区分事实、估算和推断。
输出市场规模、竞争格局、增长驱动因素、风险和待验证问题。
```

字段:

| 字段 | 必填 | 说明 |
|---|---|---|
| `name` | 是 | 1-64 位字母、数字、`_`、`-`;首字符必须是字母或数字 |
| `description` | 是 | 供主 Agent 判断何时使用 |
| `model` | 否 | 子 Agent 使用的模型;留空继承父会话 |
| `tools` | 否 | 允许的工具列表;留空使用内置 `worker` 工具集 |
| `max_turns` | 否 | 最大模型/工具循环步数;默认 20 |
| `timeout` | 否 | Go duration,例如 `30s`、`10m`;默认 15 分钟 |

Markdown 正文作为智能体角色指令。

## 调用方式

主 Agent 可调用:

- `agent_search`:发现当前用户和项目可用的智能体。
- `spawn_agent`:异步派发自包含任务并立即返回 run ID。
- `wait_agents`:等待一组 run 全部完成或任一完成。
- `read_agent_output`:读取实时状态和当前输出。
- `cancel_agent`:取消不再需要的 run。
- `list_agents`:列出当前父会话派发的 run。
- `agent`:兼容的同步委派入口。

Foya 内置三个角色:

| 角色 | 用途 | 默认工具 |
|---|---|---|
| `explorer` | 只读代码分析 | `read`、`skill_search`、`skill_load` |
| `researcher` | 外部资料研究 | `web_search`、`web_fetch`、`skill_search`、`skill_load` |
| `worker` | 代码实现与验证 | `read`、`bash`、`write`、`edit`、`skill_search`、`skill_load` |

未指定智能体时使用内置 `worker`。独立任务应先连续调用多个 `spawn_agent`,再统一 `wait_agents`,以获得真实并发。当前多个 `worker` 共享项目工作目录,主 Agent 应按文件或模块明确划分任务所有权,避免并发修改同一文件。

上下文可显式选择 `none`、`selected`、`summary` 或 `last_n_turns`。默认 `none` 要求任务文本自包含;需要父会话事实时应传递所需消息,避免盲目复制整个上下文。

## 权限

- Child Session 继承父会话的模型连接、项目和审批模式。
- 自定义智能体只能缩小工具面,不能扩大系统权限。
- Child Session 不提供任何 Agent 控制工具,默认禁止递归派工。
- 子 Agent 的审批请求通过父会话事件流展示,可由任一已连接客户端处理。
- 删除父会话会递归停止并删除其 Child Session。

## 查询接口

```text
GET /agents
GET /projects/{project_id}/agents
GET /sessions/{session_id}/children
POST /sessions/{session_id}/agents
GET /sessions/{session_id}/agents
GET /sessions/{session_id}/agents/{run_id}
POST /sessions/{session_id}/agents/wait
POST /sessions/{session_id}/agents/{run_id}/cancel
GET /sessions/{session_id}/agent-budget
```

默认全局并发和单根 run 并发均为 4。可在桌面端“设置 → Agent”中调整,保存后立即应用到后续调度。配置持久化在 Foya 数据目录的 `agent-limits.json`:

```json
{
  "max_global_concurrency": 4,
  "max_per_root": 4,
  "max_tree_tokens": 0
}
```

字段说明:
- `max_global_concurrency`:整个内核同时运行的 Child 数(1~256)
- `max_per_root`:单个根任务同时运行的 Child 数(1~256)
- `max_tree_tokens`:单个根任务累计可消耗的 Token 上限,0 表示不限制

> 当前子 Agent 在创建时会被移除所有 `agent*` 派工工具,因此无法递归创建更深层的 Child,调度层级固定为 1。为防止程序错误或模型循环导致单任务 Child 会话、磁盘日志、Token 消耗无限膨胀,内核内部为单根 run 保留了一个较大的 Child 总数安全上限(固定值,不对外暴露、不可由用户配置),当达到该上限时新派工会被拒绝。

手工编辑配置文件后需重启内核。配置文件不存在时,首次默认值可由 `FOYA_AGENT_MAX_GLOBAL_CONCURRENCY`、`FOYA_AGENT_MAX_PER_ROOT`、`FOYA_AGENT_MAX_TREE_TOKENS` 环境变量提供。

桌面端在父工具卡片中订阅 Child Session 事件,实时展示状态、耗时、Token、思考、工具调用和输出。重启后未完成 run 显示为 `interrupted`,不会自动重放工具。

CLI:

```text
foya agents
foya agents --project {project_id}
```
